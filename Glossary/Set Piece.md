The [[Player]]s only experience the game through the [[Game Master]]'s description of the current Set Piece. They should highlight details that allow the [[Player]]s to make informed decisions about their [[Character]]'s actions. By picking and choosing what is described, the [[Game Master]] can set the mood, express themes, and encourage [[Player]]s to interact with [[Scene Feature]]s.
